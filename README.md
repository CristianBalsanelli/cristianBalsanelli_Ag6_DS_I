# cristianBalsanelli_Ag6_DS_I </br>

💰 Calculadora de Desconto em Python 3 </br></br>

📋 Sobre o projeto</br>

Este projeto foi desenvolvido em Python com o objetivo de calcular automaticamente o valor final de uma compra após a aplicação de um desconto.</br>
O percentual de desconto é definido de acordo com o valor total da compra, utilizando estruturas condicionais if, elif e else.</br>
Este projeto faz parte dos meus estudos de lógica de programação e desenvolvimento em Python.</br></br>

🎯 Objetivo</br>

Desenvolver um programa capaz de:</br>
Receber o valor total de uma compra;</br>
Identificar a faixa de valor da compra;</br>
Aplicar automaticamente o percentual de desconto correspondente;</br>
Exibir o percentual de desconto concedido;</br>
Calcular e apresentar o valor final a ser pago.</br></br>

🧮 Regras de desconto</br>

Valor da compra	Desconto</br>
Menor que R$ 200,00	5% </br>
De R$ 200,00 até menor que R$ 300,00	10% </br>
R$ 300,00 ou mais	15% </br>
Exemplos </br>
Compra de R$ 150,00 → desconto de 5% → paga R$ 142,50 </br>
Compra de R$ 250,00 → desconto de 10% → paga R$ 225,00 </br>
Compra de R$ 350,00 → desconto de 15% → paga R$ 297,50 </br></br>
